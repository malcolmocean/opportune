You choose the people

For people who like some people.

This isn't a meet-strangers app. You mark the friends you'd like to see more of, and it only ever looks for chances with them.

  • Tiers and per-friend settings. Acquaintance, friend or trusted sets the defaults, and you can override any of them for one person.
  • Private effort levels. How far you'd go out of your way for someone stays on your side. They never see it.
  • Friends of friends, if you want. If Bob's friends tend to be your kind of people, you can be more open to them. Bob has to agree to vouch first.

How it works

Quiet by default. The AI only steps in when something concrete happens.

Plain rules spot the overlap. An AI judge then decides whether it's worth interrupting you, and every decision is logged so you can correct it.

SourcesA calendar link, a location app, your RSVP emails. Each is one setup step.
LogEverything becomes a timestamped observation: where you were, what you're going to.
TriggersSimple rules find overlap: same event, within a few blocks, both free.
JudgeAn AI weighs it against your settings, quiet hours and recent nudges.
NudgeYour phone buzzes with one tap to act, and one tap to say it got it wrong.
It learns your taste in interruptions

It shows you what it didn't say, too.

Every choice it makes is on the record, including the times it stayed quiet. A daily digest lists what it skipped. Rate any call good or bad and it adjusts, per friend.

After you've said yes to a friend's drop-in a few times, it offers to start saying yes for you. Trust builds up from small things you've already approved.

Better with one friend

Useful alone. Much better in pairs.

On day one it reads your own RSVPs, calendar and location. When it finds a friend you'd like to see more of, it hands you an invite link for them.

Once they join, your agents can compare notes privately: "is she free Thursday?" gets an answer without either of you sharing your whole calendar.

The drop-in problem

You texted to see if you could drop by. She replied after you'd gone home.

With porchlight, she's already said evenings are open. Her agent sees you're a block away, says "likely yes", and gives her a few minutes to veto. You get a nudge while you're still in the checkout line.

Agents talking to agents

Your agent asks theirs. Their rules decide the answer.

Every person has an agent that can answer questions from friends' agents, limited to what that friend is allowed to know. It works the same on one shared server or between servers run by different people.

# Dev's agent asks Rosa's, signed with Dev's key
POST https://rosa.example/q
{
  "kind": "dropin",
  "text": "Dev is a block away. OK if she stops by?",
  "window": "now → 19:30"
}

# Rosa's agent answers under Rosa's policy
{
  "answer": "likely",
  "text": "She's home and her porchlight is on until 8.",
  "revealed": { "porchlight": "open" }
}
  • Permission classes, not free-for-all. Availability, drop-in, plans and whereabouts are separate asks with separate grants and rate limits.
  • Signed requests. Each person has a keypair. Invite codes work once, so a leaked link does nothing.
  • Nodes that grow each other. If your friend's node can't answer something, it says what plugin would help, and you get a one-line offer to set it up.
  • An audit log. Every question a friend's agent asked yours, and what it was told.
Federated

Sign up on ours, or run your own. You can still be friends.

The protocol is open and every node speaks it. Run a node on a spare box for you and your housemates, and your agents still talk to everyone on the shared server.

Sources, triggers, channels and question types are all plugins: one folder each. If you want opportune to read your climbing gym check-ins, you can add that tonight.

Get started

About three minutes, and every choice can be changed later.

Easiest with an invite from a friend who's already on. Without one, you still get the solo features from day one.

Shared node

Sign up

  1. Open your invite link, start the Telegram bot, or open the web app.
  2. Confirm your name. Home is worked out from where your phone sleeps, or set in one tap.
  3. Hook up what you like: a calendar link, a location app, your RSVP emails.
  4. Name the people you'd like to see more of. Each gets an invite.
  5. Set your porchlight: open evenings, weekends, or ask each time.

Your own node

Self-host

Node 24 and SQLite. Bring an Anthropic key for the judge and a Telegram bot token for nudges.

git clone https://github.com/malcolmocean/opportune
cd opportune && pnpm install
cp .env.example .env  # keys + NODE_URL
pnpm start

Your node publishes what it supports at /.well-known/opportune, so other nodes know what they can ask it.
